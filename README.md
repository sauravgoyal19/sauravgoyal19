## 🔭 Currently building

**[Fortuna Personal Finance](https://github.com/sauravgoyal19/FortunaFinance)** —
an offline-first personal finance desktop app for Windows (Electron + TypeScript +
React). AES-256/SQLCipher encrypted local database, exact integer money math
(no floating-point drift), CSV/QIF/OFX import with fuzzy dedupe, full-text
search, budgets with rollover, cash-flow forecasting, and 75 passing unit/integration
tests. No cloud, no telemetry — your data never leaves your machine.

## 🧠 Applied ML & data projects

| Project | What it does |
|---|---|
| [Credit Card Fraud Detection](https://github.com/sauravgoyal19/credit_card_anomaly_finder) | Compares **unsupervised** (Isolation Forest / Local Outlier Factor) vs. **supervised** (Logistic Regression) approaches to fraud detection on a highly imbalanced dataset — evaluated on minority-class F1, not just accuracy, since accuracy alone is misleading at ~0.17% fraud prevalence. |
| [Sensor Anomaly Detection (VAE)](https://github.com/sauravgoyal19/anamoly) | A Variational Autoencoder trained on multi-sensor time-series data, flagging anomalies via reconstruction error — a common pattern for industrial/IoT predictive maintenance. |
| [Fake News Predictor](https://github.com/sauravgoyal19/fake_news_predictor) | Bag-of-words text features (headline + body) with a Decision Tree classifier; ~96% test accuracy. |
| [Twitter Sentiment Analysis](https://github.com/sauravgoyal19/twitter_sentinement_analysis) | Tweet cleaning, hashtag analysis, and a Bag-of-Words/TF-IDF + Logistic Regression baseline for sentiment classification. |
| [COVID-19 India Predictions](https://github.com/sauravgoyal19/covid_19_india_predictions) | EDA and time-series forecasting (Prophet) on state-wise India COVID-19 case data. |
| [Movie Recommender](https://github.com/sauravgoyal19/movie_recommender) | Item-based collaborative filtering on the MovieLens dataset. |
